# Examples

Plain scripts against the current API. Run them from the repository root:

```bash
uv run packages/aletheca/examples/quickstart.py
uv run packages/aletheca/examples/search_and_iterate.py   # iteration needs an API key
uv run packages/aletheca/examples/batch_and_citations.py
```

Set `ALETHECA_API_KEY` for cursor paging and budget checks; see the docs index for what a key unlocks.
