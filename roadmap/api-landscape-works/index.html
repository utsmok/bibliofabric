    Academic APIs Catalog: Works, Citations, Preprints, Data, Software, OA & Integrity

    This catalog evaluates scholarly literature, citation graph, preprint, research data, software, open-access, and research-integrity APIs against 2025–2026 platform status and bibliofabric 0.7 capabilities.

    Priority Tiers:

    • Tier 1 (Wave 1 / Next Up): Highest canonical value, open/permissive licensing, clean REST/JSON (or essential preprint coverage).
    • Tier 2 (Wave 2 / High-Value Specialist): Strong domain/data/software authority or reusable protocol adapters.
    • Tier 3 (Restricted / Niche / Deprecated): Paywalled, non-redistributable ToS, narrow niche, or sunset endpoints.

Search offset/limit (1k cap); /paper/search/bulk (token cursor, cursor_start=None); POST /paper/batch (500 IDs), POST /author/batch. 1 RPS intro key. TLDRs, SPECTER2 embeddings, influential citations, citation contexts & intents, strong CS/biomed abstracts, author disambiguation. Ready today (HeaderAuth, cursor_start=None, _fetch_batch_chunk POST override with retry=True). Tier 1

    https://api.opencitations.net/index/v2
    https://api.opencitations.net/meta/v1    		 REST/JSON (+ SPARQL & dumps) Open/free; optional Access Token (authorization header). CC0 1.0 Path lookups (/citations/doi:..., /references/doi:..., /metadata/omid:...); __-separated path batching; unpaged (page_size_param=None). 180 req/min/IP. First-class auditable citation links (OCIs) & OMID crosswalks unifying Crossref, DataCite, NIH-OCC, OpenAIRE, JaLC. (COCI/POCI/Index v1 deprecated.)     https://www.ebi.ac.uk/europepmc/webservices/rest
    /annotations_api    		 REST/JSON & XML Open/free, no API key. Metadata open; full-text per-article CC license. cursorMark (* → nextCursorMark), pageSize max 1,000. Citations/refs page/pageSize. Annotations batch 1–8 IDs. Polite ~1–10 RPS. Life-science articles, preprints, grants, JATS full text, text-mined bio-annotations (genes/UniProt, diseases, chemicals, data links), PMID/PMCID/DOI crosswalk. Ready today (cursorMark + pageSize). JATS XML needs XML helper. Tier 1

    https://eutils.ncbi.nlm.nih.gov/entrez/eutils/

US Public Domain (metadata; PMC OA per-article CC). 2-step esearch (retstart/retmax, WebEnv history) → esummary (JSON) or efetch (XML only). 3 RPS keyless / 10 RPS with key. Authoritative MeSH indexing, MEDLINE curation, structured PubMed XML, NCT/grant tags, PMC OA tarballs. Needs XML decoder for efetch; QueryParameterAuth works for esearch/esummary. Tier 2
    DBLP Docs
    https://dblp.org/search/publ/api
    /author/api, /venue/api    		 REST/JSON, XML, RDF Open/free, no API key. CC0 1.0 f (offset) + h (hits up to 1,000), format=json. Strict anti-burst throttling (keep ≤1 RPS or use XML/RDF dumps). Gold-standard CS publication & author disambiguation (PIDs) and conference/series hierarchy. Ready today (offset_param="f", page_size_param="h", result.hits.hit unwrapper). Tier 2
    INSPIRE-HEP Docs
    https://inspirehep.net/api/    		 REST/JSON (+ BibTeX/LaTeX) Open/free, no API key for read. CC0 (no bulk author email harvesting). page + size (up to 1,000; 10k ES cap) + links.next. 15 req / 5s per IP (429s count against rolling window — wait ≥5s). High-energy physics literature, collaborations/experiments, arXiv↔journal canonical records, HEP citations. Ready today (Invenio JSON; recommend ≥5s 429 cooldown). Tier 2
    NASA ADS / SciXplorer Docs
    https://api.adsabs.harvard.edu/v1/    		 REST/JSON (Solr) Free Bearer token (Authorization: Bearer). Open metadata (abstracts/full-text per publisher). Solr start/rows (max 2,000) + cursorMark; POST /metrics & /export/*. 5,000 req/day (X-RateLimit-*). Astronomy, planetary & Earth/heliophysics bibcodes, curated telescope/dataset links, full-text search, astro citation graph. Ready today for /search/query (StaticTokenAuth + cursorMark). Tier 2
    Lens.org (Scholarly & Patent) Docs
    https://api.lens.org/scholarly/search
    https://api.lens.org/patent/search    		 REST/JSON (POST DSL + GET) Paid / Member plan (14-day academic trial); Authorization: Bearer. Proprietary / Member ToS (no bulk redistribution). JSON POST (size, from, scroll). Tiered (~10–20 RPM basic); x-rate-limit-retry-after-millis. 250M+ works + 150M+ global patents + patent-to-scholarly NPL citations, clinical trials, funding. Needs POST search dialect + millisecond retry-after parsing. Tier 3
    Dimensions (DSL v2) Docs
    https://app.dimensions.ai/api/dsl/v2    		 Custom DSL POST Paid institutional or approved free non-commercial scientometrics grant only. API key → /auth.html → 2h JWT. Proprietary / Restricted ToS. DSL limit (1,000) + skip (50k cap); 30 req/min/IP. Publications, grants, patents, clinical trials, policy documents, orgs. Poor fit (custom DSL + non-OAuth JWT + restricted ToS). Tier 3

    Decentralized Standards & Shared Protocol Adapters

    Rather than building single-site wrappers for hundreds of institutional repositories, bibliofabric and the canonical layer can support four open standards as reusable protocol adapters:

    Standard Specification Wire Format Role in Stack Target Layer Priority
    OAI-PMH openarchives.org/pmh XML (resumptionToken cursors) Universal fallback metadata harvester for institutional repos, EarthArXiv, PhilArchive, arXiv bulk. Shared bibliofabric XML harvester mixin Tier 2
    FAIR Signposting signposting.org HTTP HEAD / Link headers (cite-as, author, describedby, license) Discover canonical PIDs, authors, licenses, and machine-readable metadata URLs on any scholarly landing page. Shared bibliofabric Link-header helper Tier 2
    CodeMeta & CITATION.cff codemeta.github.io
    citation-file-format.github.io    		 JSON-LD (codemeta.json) & YAML (CITATION.cff) Parse intrinsic software citation metadata directly from GitHub/GitLab, Zenodo, or Software Heritage archives. Canonical fusion Software entity parsers Tier 2
    COAR Notify coar-notify.net Linked Data Notifications / ActivityStreams 2.0 Link preprints, peer reviews, overlay journals, and Software Heritage deposits via standardized event payloads. Canonical fusion event/relation adapter Tier 2
