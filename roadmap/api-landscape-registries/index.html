    Academic APIs Catalog: Authority Registries, Organizations, Venues, Funders & Taxonomies

    This catalog covers the canonical authority registries, persistent-identifier routers, and controlled vocabularies needed to anchor authors, institutions, journals, books, publishers, funders, grants, and subjects across scholarly graphs.

    Priority Tiers:

    • P0 (Foundational Backbone): Required for canonical entity grounding; build first (Wave 1).
    • P1 (High Canonical Value): High-impact enrichment sources (Wave 2).
    • P2 (Domain / Regional Enrichment): Valuable regional or discipline authorities and lightweight helpers.
    • P3 (Bulk Table / Commercial / Skip): Periodic CSV lookup tables, paywalled services, or closed portals.

    ORCID API v3.0 Docs
    Public: https://pub.orcid.org/v3.0
    Member: https://api.orcid.org/v3.0    		 REST JSON (Accept: application/vnd.orcid+json) or XML Anon (public); free Public Client OAuth2 (/read-public, non-commercial); paid Member API. Public API Terms (non-commercial); annual public data file CC0. 12 req/s (24 member), burst 40/s → 503; 25k/day anon / 100k/day public. Search start/rows (10k cap). No multi-ID batch. Author-asserted bio, verified employment/education timelines (ROR/Ringgold), curated works, cross-PID links (ISNI/Scopus/ResearcherID). Good fit (ClientCredentialsAuth(token_auth_method="post"), normalize_orcid). Needs default Accept header, daily quota guard, XML-style JSON unwrapper. P0
    Wikidata (REST v1, Action, SPARQL) & Scholia Docs
    REST: https://www.wikidata.org/w/rest.php/wikibase/v1
    Action: https://www.wikidata.org/w/api.php
    SPARQL: https://query.wikidata.org/sparql    		 REST JSON, Action JSON, SPARQL Free (optional OAuth2). Descriptive User-Agent required or immediate 429. CC0 1.0 Action wbgetentities batches 50 QIDs/req. SPARQL 60s timeout, ~5 conc. Honor Retry-After. Universal PID crosswalk hub (ORCID, ISNI, VIAF, GND, LCCN, IdRef, ROR, ISSN, DOI, OpenAlex), multilingual labels, deceased dates, Scholia templates. Moderate fit (wbgetentities dict unwrapper, normalize_wikidata_qid, optional SPARQL helper). P0
    Lobid-GND (hbz / DNB) Docs
    https://lobid.org/gnd (/search, /{id}.json, /reconcile)    		 REST JSON-LD + Reconcile API Free, no key. CC0 1.0 ES from/size + scroll; polite throttling (especially /reconcile). DACH/European researchers, corporate bodies, subjects, biographical dates, sameAs links to VIAF/ISNI/Wikidata/ORCID. Strong fit (offset_param="from", page_size_param="size", valid JSON). P1
    VIAF (OCLC) Docs
    https://viaf.org/viaf/ (/{id}/viaf.json, /AutoSuggest, /search)    		 REST JSON/JSON-LD + SRU (XML) Free public read (modernized 2025–2026 OAS 3.0 infrastructure). ODC-BY 1.0 Polite limits; SRU startRecord/maximumRecords. No multi-ID batch GET. Global meta-authority clustering 60+ national libraries (humanities and historical authors lacking ORCIDs). Moderate fit (JSON cluster + AutoSuggest; SRU XML needed for /search). P1
    Library of Congress Linked Data (id.loc.gov) Docs
    https://id.loc.gov/authorities/names/ (/suggest2, /{lccn}.json)    		 REST JSON (suggest2), JSON-LD, SKOS Free, no key. Public Domain / CC0 Strict IP bans: JSON 20 req/min (1h block); MARCXML 30 req/min (72h rolling block). Authoritative North American name authority (LCNAF) & subjects (LCSH) with exactMatch to VIAF/ISNI/Wikidata. Needs strict per-minute window limiter to prevent IP bans. P2
    IdRef (ABES) Docs
    https://www.idref.fr/Sru/Solr (?wt=json)
    https://www.idref.fr/{ppn}.json    		 Solr REST JSON + RDF/XML + OAI-PMH Free, no key. Etalab Open Licence 2.0 Polite fair-use; Solr start/rows. French higher-ed/researcher authority (Sudoc, theses.fr, HAL): thesis advisors/juries, ORCID/ISNI/BnF crosswalks. Good fit for Solr ?wt=json (offset_param="start"). P2
    BnF (data.bnf.fr & catalogue.bnf.fr) Docs
    https://data.bnf.fr/sparql
    https://catalogue.bnf.fr/api/SRU    		 SPARQL + SRU 1.2 (XML) + JSON-LD Free, no key. Etalab Open Licence 2.0 Polite fair-use; SRU startRecord/maximumRecords. Francophone & historical monograph/author authority (ARK PIDs, FRBR Work/Expression/Manifestation graph). Poor fit natively (requires XML SRU + SPARQL extensions). P2
    ISNI (ISO 27729) Docs
    https://isni.oclc.org/sru/    		 SRU XML (+ AtomPub for RAs) Free basic SRU; heavy/bulk/RA use requires ISNI-IA agreement. Restricted bulk Polite SRU limits; startRecord/maximumRecords. Bridges authors, editors, publishers, and Ringgold. Consume via Wikidata/VIAF/ORCID/ROR first; SRU secondary. Poor fit (XML-only SRU + licensing friction). P2/P3
    Loop (Frontiers) & ResearchGate Closed Proprietary Strictly closed; ToS prohibits scraping. Proprietary N/A Superseded by ORCID + OpenAlex + Semantic Scholar. Do not integrate. P3 (Skip)

    ROR API v2 (incl. Open Funder Registry merger) Docs
    https://api.ror.org/v2/organizations (v1 sunset late 2025)    		 REST JSON Free; registered Client-Id header recommended for full quota. CC0 1.0 (API & Zenodo dumps) 2,000 req / 5 min (~50/5min unregistered). page (1-based, max 20/page, 10k cap). ?affiliation= (single_search mid-2026). #1 canonical org & funder authority. Absorbed Crossref Open Funder Registry. Parent/child hierarchy, geo/continents, domains, ISNI/Wikidata/GRID/FundRef crosswalks, best affiliation matcher. Excellent fit (normalize_ror, max_offset=10_000). Needs 5-min window limiter & match_affiliation() helper. P0
    GLEIF LEI API v1 Docs
    https://api.gleif.org/api/v1/lei-records    		 REST JSON:API (application/vnd.api+json) Free, no key. CC0 1.0 60 req/min/IP. page[number]/page[size] (1–200); comma-batch filter[lei]=ID1,ID2; /fuzzycompletions. Authoritative ISO 17442 legal-entity registry with parent/ultimate-parent corporate ownership (resolves corporate publishers, pharma/biotech sponsors). Good fit (needs JSON:API unwrapper, comma batching, 60/min window limiter, normalize_lei). P1
    DEQAR API v2 (EQAR) Docs
    https://backend.deqar.eu/webapi/v2/    		 REST JSON Free with registration + Bearer JWT via POST /accounts/get_token/. Public open data Fair-use; limit/offset. European Higher Education Area (EHEA) accreditation, QA agencies, ETER/DEQAR IDs, historical institution mergers. Good fit (needs non-OAuth2 JWT auth strategy). P2
    ETER III / EHESO API v4.0 Docs
    https://eter-project.com/api/4.0/ (POST /HEIs/query)    		 REST JSON (POST query) Free for research/policy; account + POST /users/login JWT Bearer token. EC open research data terms Fair-use; MongoDB-style JSON filter body. European university statistics (student/staff counts, PhDs awarded, R&D expenditure, ETER ↔ ROR crosswalk). Needs POST-body search dialect + custom JWT login auth. P2
    Wikidata (Org role) Same as Authors REST / Action / SPARQL Free (User-Agent required). CC0 1.0 Same as Authors (50 QID batch via Action API). Bridges ROR, ISNI, Ringgold, LEI, GND, GRID, OpenAlex, plus inception dates/logos/multilingual names. Same as Authors. P0
    Ringgold Identify & OpenCorporates ringgold.com
    OpenCorporates api.opencorporates.com/v0.4/    		 REST JSON Ringgold: paid only. OpenCorporates: 50/day free (ODbL) or commercial. Proprietary / ODbL Restricted. Skip Ringgold (resolve passively via Wikidata/ORCID/ISNI); GLEIF LEI (CC0) covers ~90% of corporate needs over OpenCorporates. Skip / P3. P3

    https://doaj.org/api/v4/ (v1–v3 deprecated)    		 REST JSON None for public read (API key for publisher upload; real-time bulk dumps paid, 1-mo lagged free). CC0 1.0 ~2 req/s (429 above threshold). page, pageSize (max 100). Batch via Lucene OR (issn:A OR issn:B).     ISSN Portal / ROAD / Keepers Registry Docs
    https://portal.issn.org/resource/ISSN/{issn}?format=json
    https://keepers.issn.org/    		 JSON-LD ConNeg (free); REST/OAI (paid) Free individual Linked Data ConNeg lookup; bulk REST/OAI-PMH requires paid ISSN IC subscription. Free ConNeg non-bulk; full register paid. Polite individual ConNeg lookup only (no public search/batch without license). Authoritative ISSN-L (collapsing print+electronic ISSNs), official key title, title history, ROAD OA status, Keepers archival preservation (CLOCKSS/Portico/LOCKSS). Moderate fit (single-ISSN JSON-LD @graph parser). P0
    Open Policy Finder (Jisc) (formerly Sherpa RoMEO & Juliet) Docs
    https://api.openpolicyfinder.jisc.ac.uk (Sherpa v2 retired July 2026)    		 REST JSON (or XML) Required free API key in x-api-key header (no longer query param). CC BY-NC-ND 4.0 (tag in fusion!) Jisc per-key quota; limit/offset; filter by issn, item-type. Canonical Green OA / self-archiving & funder OA mandate policies (permitted versions, embargoes, repositories). Strong fit (HeaderAuth("x-api-key", ...), JSON array filter serializer). P1
    Mir@bel Docs
    https://reseau-mirabel.info/api    		 REST JSON Free, no key for public read. Etalab Open Licence Polite limits; ISSN & multi-title filtering. Francophone/European journal access, publisher policies (partnering with Open Policy Finder/DOAJ), institutional availability. Strong fit (clean REST JSON). P2
    HK-dir (Kanalregisteret) Docs
    https://kanalregister.hkdir.no/api/krtabeller/    		 REST JSON / CSV (DBH tables 850–853) Free, no key. NLOD 2.0 Polite limits; bulk table sync preferred. Nordic Level 0/1/2 quality ratings, OA status, and scholarly book publisher authority (Level 1/2). Snapshot loader or lightweight DBH table client. P1/P2
    JUFO (Publication Forum, Finland) Docs
    https://jufo-rest.csc.fi/v1.1/    		 REST JSON Free, no key. CC BY 4.0 / CC0 Polite limits; query by nimi, issn, isbn root, tyyppi (journal/book publisher/conference). Finnish Level 0/1/2/3 ratings covering journals, book publishers (by ISBN prefix), and CS/engineering conferences. Strong fit (simple REST JSON). P2
    Crossref Members / Prefixes / Journals https://api.crossref.org (/members, /prefixes, /journals) REST JSON Free (mailto polite pool). Open bibliographic metadata Crossref dynamic pools; rows/offset/cursor. Maps DOI prefixes → Publisher Members and tracks journal deposit coverage rates. Already built in stavrophora. P0 (Existing)
    Open Library Docs
    https://openlibrary.org (/isbn/{isbn}.json, /api/books, /search.json)    		 REST JSON Free; descriptive User-Agent requested. CC0 1.0 Polite traffic; page/limit search; /api/books?bibkeys=ISBN:A,ISBN:B batching. Primary open ISBN-10/13 → Edition → Work resolver, OCLC/LCCN crosswalks, subjects, Internet Archive links. Good fit (custom bibkeys batching + normalize_isbn). P1
    Google Books Docs
    https://www.googleapis.com/books/v1/volumes    		 REST JSON API key required (key query param). Proprietary Google ToS (caching/redistribution limits). 1,000 req/day default; startIndex/maxResults (max 40). Broad monograph ISBN coverage, page counts, descriptions, BISAC categories. Good fit (QueryParameterAuth), but restricted ToS limits redistribution. P2
    LoC Catalog SRU Docs
    http://lx2.loc.gov:210/lcdb    		 SRU XML (MARCXML/MODS) Free, no key. Public Domain Strict 20–30 req/min (multi-hour IP bans on exceed). Authoritative MARC/MODS monograph metadata, LCSH, LCC call numbers, ISBN→LCCN. Poor fit (XML SRU + strict rate cap). P2
    WorldCat v2, ISBNdb, Latindex, SJR, CWTS, MIAR WorldCat, api2.isbndb.com, latindex.org, scimagojr.com, journalindicators.com, miar.ub.edu Paid REST or CSV/XLSX bulk downloads Paid (WorldCat/ISBNdb) or no public REST API (Latindex/SJR/CWTS/MIAR). Proprietary / Non-commercial CSV Bulk dumps or paid tiers. Handle Latindex/SJR/CWTS/MIAR as optional periodic local lookup tables rather than live HTTP clients. Skip live clients. P3

    RAiD (ISO 23527) Docs
    https://api.raid.org (/raid/, /raid/{prefix}/{suffix})    		 REST JSON (OAS 3.0) Free read-only Federation Search API (minting requires Service Point OAuth2). Open metadata (ARDC RA) Polite limits; OpenAPI list/search endpoints.     NIH RePORTER v2 Docs
    https://api.reporter.nih.gov/v2/ (/projects/search, /publications/search)    		 REST JSON (POST body) Free, no key. Public Domain (US Federal Gov) ≤1 RPS recommended; JSON body limit (max 500) + offset (max 9,999 → 10k cap/query). Batch by project_nums array. World's largest biomedical grant database: exact funding amounts, PIs, activity codes, MeSH/RCDC, Grant ↔ PMID links. Needs POST-body search dialect. P1
    NSF Award Search Docs
    https://api.nsf.gov/services/v1/awards.json    		 REST JSON (or XML) Free, no key. Public Domain (US Federal Gov) offset + rpp (max 25/req; 3,000 cap/query — chunk by date/directorate). Obligated & total NSF funds, PIs/co-PIs, program officers, directorates, awardee UEI. Strong fit (offset_param="offset", page_size_param="rpp", max_page_size=25). P1
    UKRI Gateway to Research (GtR) Docs
    https://gtr.ukri.org/gtr/api/    		 REST JSON (vendored Accept) Free, no key. OGL v3.0 p (1-based page) + s (size, max 100). Requires Accept: application/vnd.rcuk.gtr.json-v7. All 7 UK Research Councils + Innovate UK: grants, tranches, PIs, orgs, publications, collaborations, outcomes. Good fit (page_param="p", page_size_param="s"); needs default Accept header. P1
    EU CORDIS / OpenAIRE Projects CORDIS SPARQL
    OpenAIRE Projects: aireloom    		 SPARQL / Bulk dumps (CORDIS); REST JSON (OpenAIRE) Free, no key. CC BY 4.0 SPARQL fair-use; bulk Horizon Europe/H2020/FP7 dumps. aireloom already aggregates CORDIS + 30+ global funders (EC, NSF, NIH, Wellcome, SNSF, ARC, DFG, UKRI).     ARC NCGP (Australia) Docs
    https://dataportal.arc.gov.au/NCGP/API/grants    		 REST JSON:API Free, no key. CC BY 4.0 page[number], page[size]. Australian competitive grants since 2001 with ANZSRC FoR codes, orgs, and budgets. Good fit once JSON:API unwrapping helper is available. P2
    SNSF Data Portal (Switzerland) Docs (https://data.snf.ch/datasets) REST JSON / Bulk CSV+JSON Free, no key. CC0 / Open Data Swiss Polite limits; bulk downloads (90k+ grants since 1975). Swiss grants with linked publications, datasets, researcher career outcomes, ORCIDs. Bulk dataset loader + lightweight client. P2
    DFG GEPRIS (Germany) https://gepris.dfg.de/ Web portal only No official public REST API. Restricted portal terms N/A Consume indirectly via OpenAIRE Projects (aireloom) and Crossref funding metadata. Do not scrape. P3 (Skip)

    DOI Foundation / Handle.net & Content Negotiation Docs
    RA Lookup: https://doi.org/ra/{doi1},{doi2}
    Handle: https://doi.org/api/handles/{doi}
    ConNeg: https://doi.org/{doi}    		 REST JSON (RA/Handle) + HTTP Content Negotiation (csl+json, x-bibtex, schemaorg.ld+json) Free, no key. Open resolution infrastructure (metadata license per RA). High availability; /ra/{doi1},{doi2} batches Registration Agency lookups. Critical routing layer: distinguishes Crossref (stavrophora) vs. DataCite vs. JaLC/mEDRA/KISTI before wasted 404 fan-out; ConNeg provides universal fallback metadata. Strong fit (follow_redirects=True ready; needs default Accept header & raw text hook for BibTeX/RDF). P0
    Identifiers.org (EMBL-EBI) Docs
    https://resolver.api.identifiers.org/{curie}
    https://registry.api.identifiers.org/restApi/namespaces    		 REST JSON Free, no key. CC0 / Apache-2.0 Polite limits; namespace registry cacheable locally. Authoritative CURIE namespace registry & regex validation for 800+ scientific PIDs (pubmed:, uniprot:, pdb:, rrid:, biostudies:). Strong fit (REST JSON + local cached namespace snapshot). P1
    MeSH (NLM Linked Data) Docs
    https://id.nlm.nih.gov/mesh/lookup/descriptor
    https://id.nlm.nih.gov/mesh/{id}.json    		 REST JSON, JSON-LD, SPARQL Free, no key. Public Domain / CC0 Polite limits; limit param; annual RDF/XML dump available. Gold-standard biomedical controlled vocabulary with hierarchical Tree Numbers (C04.588...), qualifiers, entry terms, PubMed alignment. Good fit for Lookup & /{id}.json; SPARQL optional for deep trees. P1
    ARK / N2T Docs / N2T
    https://n2t.net/ark:/{naan}/{name}    		 HTTP Redirect / ERC (ANVL plain text) / NAAN JSON Free, no key. Open infrastructure Polite limits; NAAN registry cacheable locally. Resolves archival, library (BnF/CDL/Gallica), museum, and cultural-heritage PIDs lacking DOIs. Lightweight helper + ANVL parser (not full ResourceClient). P2
    LCSH (id.loc.gov) Docs
    https://id.loc.gov/authorities/subjects/suggest2    		 REST JSON (suggest2) + JSON-LD Free, no key. Public Domain / CC0 Strict 20 req/min cap (avoid IP bans via caching). Broadest humanities/social-sciences/library subject taxonomy; crosswalks to Dewey/LCC/Wikidata/FAST. Needs per-minute window limiter & caching. P2
    UNESCO Thesaurus (Skosmos) Docs
    https://vocabularies.unesco.org/browser/rest/v1/thesaurus/    		 REST JSON-LD (Skosmos v1) Free, no key. CC BY-SA 3.0 IGO Polite limits; maxhits param. Multilingual (EN/FR/ES/RU/AR) SKOS hierarchy; reusable client works against any Skosmos vocabulary server. Strong fit (standard Skosmos JSON-LD). P2
    ANZSRC 2020 FoR (ARDC) Docs
    https://vocabs.ardc.edu.au/repository/api/lda/anzsrc-2020-for/resource.json    		 REST JSON (LDA/SKOS) + SPARQL Free, no key. CC BY 4.0 Polite limits (~1,500 concepts — ideal local cache). 2/4/6-digit discipline hierarchy used by Dimensions, ARC, Figshare, AU/NZ CRIS systems. Static cached snapshot or thin client. P2
    SPDX Licenses, CRediT & OECD FOS SPDX
    CRediT (Z39.104)
    OECD FOS (Frascati SKOS)    		 Static JSON / JSON-LD / SKOS (HTTP + ETag) Free, no key. CC0 / CC BY 4.0 Bundle or cache locally with ETag (0 live calls needed).
