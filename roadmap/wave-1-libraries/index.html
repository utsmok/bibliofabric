    Wave 1 libraries

    Wave 1 adds eleven single-source client libraries to the three existing ones. Each library covers every public read endpoint of its upstream API and models every field the API returns. Write endpoints are out of scope for this wave. The deferred list records what was left out and why.

    The libraries are not yet published on PyPI. The release section lists what each first release needs.

    Roster

    Library Package Covers Upstream docs
    ROR rorifer Organization records, search, filters, affiliation matching, registry dumps on Zenodo REST API
    Zenodo zenotheca Record search, record versions, files and downloads, communities, vocabularies, OAI-PMH harvesting REST API
    DataCite dataphora DOIs, activities, clients, providers, repositories, prefixes, events, GraphQL queries REST API
    OpenCitations opcitato Citation links, references, citation counts, and metadata API documentation
    DOI RA and content negotiation hodoi Registration agency lookup, metadata by media type, handle records DOI resolution documentation
    Semantic Scholar scholiast Papers, authors, citations, references, search, batch lookup, recommendations, patents, snippets, and dataset releases API docs
    ORCID orchis Researcher records, person sections, activities, and both public search routes Public API guide
    Europe PMC europaea Literature search, article records, full text, references, citations, data links, evaluations, annotations, grants, profiles, and preprints Web services
    Wikidata quiddita Entities, claims, sitelinks, lexemes, search, entity data in RDF formats, utility modules, and SPARQL Action API
    DOAJ diurnalia Journal and article search, journal and article records API v4 docs
    ISSN Portal seriatim ISSN and ISSN-L records as JSON-LD, the free search, and the Title Word Abbreviation list ISSN Portal

    Names

    The names follow the existing family. aireloom weaves OpenAIRE, aletheca is a library of truth for OpenAlex, and stavrophora is Greek for "cross bearer", after Crossref. Each Wave 1 name is a Latin or Greek word that points at its source.

    Package Origin
    rorifer Latin for "dew bearing" (ros, roris), and it starts with ROR.
    zenotheca Zeno plus theca (library). Zenodo is named after Zenodotus, the first librarian of Alexandria.
    dataphora "Data bearer", the DataCite counterpart of stavrophora.
    opcitato From opere citato ("in the work cited"), the "op. cit." of footnotes.
    hodoi Greek for "roads" or "ways". The client routes a DOI to its registration agency, and the word contains "doi".
    scholiast A scholar who writes scholia, the notes in the margins of a text.
    orchis The Greek and botanical name of the orchid, after ORCID.
    europaea Latin for "European", after Europe PMC.
    quiddita From quidditas ("whatness"), for the Q identifiers of Wikidata.
    diurnalia Latin for daily records, the root of "journal", after the Directory of Open Access Journals.
    seriatim Latin for "one after another", for serials and their ISSNs.

    Each name has three spellings: the distribution and import name (rorifer), the prefix of the settings environment variables (RORIFER_MAX_CONCURRENCY), and the prefix of the class names (RoriferClient).

    Release

    1. Register a pending trusted publisher on PyPI for each name: owner utsmok, repository bibliofabric, workflow ci.yml, environment pypi. The publish job reads the package name from the tag <name>-v<version>, so the workflow needs no change.
    2. Tag each Wave 1 library as <name>-v0.1.0, following the release flow in the root AGENTS.md. Every library requires bibliofabric>=0.8,<0.9; bibliofabric 0.8.0 is on PyPI since 2026-11-28.

    • opcitato: Index API, Meta API, upstream quirks, API reference

    • scholiast: papers, authors, recommendations, datasets, snippets and patents, upstream quirks, API reference
