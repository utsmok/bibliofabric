    Authentication

    Auth strategies implement the AuthStrategy protocol: async_authenticate() / authenticate() mutate the outgoing httpx.Request, and async_close() / close() release resources idempotently so a single strategy instance works with both async and sync clients.

    Strategy Use case
    NoAuth Public APIs (default)
    StaticTokenAuth(token) Pre-issued bearer token
    BasicAuth(username, password) HTTP Basic authentication (e.g. DataCite)
    QueryParameterAuth(key_name, key_value) APIs authenticated by query parameter (OpenAlex api_key)
    HeaderAuth(name, value) Static credential headers (Crossref Metadata Plus crossref-api-key)
    ClientCredentialsAuth(client_id, client_secret, token_url, ...) OAuth2 client-credentials flow (Basic or POST body credentials, optional scope)
    RefreshTokenAuth(token_url, refresh_token, ...) OAuth2 refresh-token flow with token caching and rotation

    OAuth2 token caching and 401 refresh

    ClientCredentialsAuth and RefreshTokenAuth fetch a bearer token, cache it using time.monotonic() until shortly before expires_in, serialize concurrent refreshes, and expose invalidate_token(). Pass user_agent=, scope=, timeout=, or a caller-owned http_client= as needed. For token endpoints that expect credentials in the form body rather than HTTP Basic (such as ORCID), pass token_auth_method="post" to ClientCredentialsAuth.

    When a request receives HTTP 401 and the auth strategy exposes invalidate_token(), BaseApiClient invalidates the cached token and retries the request once before raising AuthError.

    Missing or invalid credentials raise ConfigurationError; a failed token fetch raises AuthError.

    from bibliofabric import ClientCredentialsAuth, RefreshTokenAuth

auth = ClientCredentialsAuth(
    client_id,
    client_secret,
    token_url,
    scope="/read-public",
    token_auth_method="post",
    user_agent=ua,
)
client = FooClient(auth=auth)

refresh_auth = RefreshTokenAuth(
    token_url,
    refresh_token,
    client_id=client_id,
    client_secret=client_secret,
)

    Secret redaction

    Auth strategies declare redacted_query_params: frozenset[str] and redacted_headers: frozenset[str] (empty by default). Built-in strategies populate these automatically (QueryParameterAuth redacts its key_name, HeaderAuth redacts its header name, and bearer/basic/OAuth2 strategies redact authorization), and BaseApiClient scrubs them from debug logs and exception messages.

    API reference

    bibliofabric.auth

    Authentication strategies for bibliofabric-family clients.

    A strategy mutates the outgoing httpx.Request in place (header or query parameter) and may hold resources closable through async_close() / close(). Strategies are shared by both client variants: one object works with an async client (async_authenticate) and a sync client (authenticate), so every strategy implements both method pairs.

    class BasicAuth:
    """Adds HTTP Basic authentication (``Authorization: Basic <base64>``)."""

    redacted_query_params: frozenset[str] = frozenset()
    redacted_headers: frozenset[str] = frozenset({"authorization"})

    def __init__(self, username: str, password: str) -> None:
        if not username or not password:
            raise ConfigurationError(
                "BasicAuth requires a non-empty 'username' and 'password'."

    async def async_authenticate(self, request: httpx.Request) -> None:
        request.headers["Authorization"] = self._header_value

    async def async_close(self) -> None:
        """Nothing to close."""

    def authenticate(self, request: httpx.Request) -> None:
        request.headers["Authorization"] = self._header_value

    def close(self) -> None:
        """Nothing to close."""

    ClientCredentialsAuth

    Bases: _OAuth2TokenAuth

    OAuth2 client-credentials flow with an in-memory token cache.

    Fetches a bearer token from token_url using client_id and client_secret and reuses it until shortly before expires_in. The cached token is shared by both client variants; each variant lazily creates its own httpx client for the token request (unless an external http_client is provided) and serializes its refreshes behind its own lock (asyncio.Lock for the async twin, threading.Lock for the sync twin). Set token_auth_method="post" for token endpoints (such as ORCID) that expect client_id and client_secret in the form body rather than an HTTP Basic header.

    class ClientCredentialsAuth(_OAuth2TokenAuth):
    """OAuth2 client-credentials flow with an in-memory token cache.

    Fetches a bearer token from ``token_url`` using ``client_id`` and
    ``client_secret`` and reuses it until shortly before ``expires_in``. The
    cached token is shared by both client variants; each variant lazily
    creates its own ``httpx`` client for the token request (unless an external
    ``http_client`` is provided) and serializes its refreshes behind its own
    lock (``asyncio.Lock`` for the async twin, ``threading.Lock`` for the sync
    twin). Set ``token_auth_method="post"`` for token endpoints (such as
    ORCID) that expect ``client_id`` and ``client_secret`` in the form body
    rather than an HTTP Basic header.
    """

    def __init__(
        self,
        client_id: str,
        client_secret: str,
        token_url: str,
        *,
        scope: str | None = None,
        token_auth_method: TokenAuthMethod = "basic",
        user_agent: str | None = None,
        timeout: float = 30.0,
        http_client: httpx.AsyncClient | httpx.Client | None = None,
    ) -> None:
        missing = [
            name
            for name, value in (
                ("client_id", client_id),
                ("client_secret", client_secret),
                ("token_url", token_url),
            )
            if not value
        ]
        if missing:
            raise ConfigurationError(
                f"ClientCredentialsAuth requires non-empty: {', '.join(missing)}."
            )
        if token_auth_method not in _VALID_TOKEN_AUTH_METHODS:
            raise ConfigurationError(
                "ClientCredentialsAuth token_auth_method must be 'basic' or 'post', "
                f"got {token_auth_method!r}."
            )
        super().__init__(
            token_url=token_url,
            user_agent=user_agent,
            timeout=timeout,
            http_client=http_client,
        )
        self._client_id = client_id
        self._client_secret = client_secret
        self._scope = scope
        self._token_auth_method = token_auth_method

    def _token_request_payload(self) -> tuple[httpx.Auth | None, dict[str, str]]:
        data: dict[str, str] = {"grant_type": "client_credentials"}
        if self._scope:
            data["scope"] = self._scope
        if self._token_auth_method == "post":
            data["client_id"] = self._client_id
            data["client_secret"] = self._client_secret
            return None, data
        return (
            httpx.BasicAuth(username=self._client_id, password=self._client_secret),
            data,
        )

    class RefreshTokenAuth(_OAuth2TokenAuth):
    """OAuth2 refresh-token flow with an in-memory access-token cache.

    Exchanges ``refresh_token`` at ``token_url`` for a bearer access token,
    caches it with ``time.monotonic()`` until shortly before ``expires_in``,
    and updates the stored refresh token when the server rotates it.
    """

    def __init__(
        self,
        token_url: str,
        refresh_token: str,
        *,
        client_id: str | None = None,
        client_secret: str | None = None,
        scope: str | None = None,
        user_agent: str | None = None,
        timeout: float = 30.0,
        http_client: httpx.AsyncClient | httpx.Client | None = None,
    ) -> None:
        missing = [
            name
            for name, value in (
                ("token_url", token_url),
                ("refresh_token", refresh_token),
            )
            if not value
        ]
        if missing:
            raise ConfigurationError(
                f"RefreshTokenAuth requires non-empty: {', '.join(missing)}."
            )
        if client_id is not None and not client_id:
            raise ConfigurationError(
                "RefreshTokenAuth 'client_id' must be non-empty when provided."
            )
        if client_secret is not None and not client_secret:
            raise ConfigurationError(
                "RefreshTokenAuth 'client_secret' must be non-empty when provided."
            )
        super().__init__(
            token_url=token_url,
            user_agent=user_agent,
            timeout=timeout,
            http_client=http_client,
        )
        self._refresh_token = refresh_token
        self._client_id = client_id
        self._client_secret = client_secret
        self._scope = scope

    def _token_request_payload(self) -> tuple[httpx.Auth | None, dict[str, str]]:
        data: dict[str, str] = {
            "grant_type": "refresh_token",
            "refresh_token": self._refresh_token,
        }
        if self._client_id is not None:
            data["client_id"] = self._client_id
        if self._client_secret is not None:
            data["client_secret"] = self._client_secret
        if self._scope:
            data["scope"] = self._scope
        return None, data

    def _store_token(
        self, payload: object, *, response: httpx.Response | None = None
    ) -> str:
        access_token = super()._store_token(payload, response=response)
        if isinstance(payload, dict):
            rotated = payload.get("refresh_token")
            if isinstance(rotated, str) and rotated:
                self._refresh_token = rotated
        return access_token
