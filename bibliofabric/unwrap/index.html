    Response unwrapping

    ResponseUnwrapper is the protocol that makes bibliofabric API-agnostic. A client implements it to teach the framework how to navigate its API's JSON envelope: where result records live, how to read a single item, the total, the next cursor, and the remaining metadata.

    class FooUnwrapper:
    def results(self, body):
        return body.get("results", [])

    def item(self, body):
        return body

    def total(self, body):
        return body.get("total")

    def next_cursor(self, body):
        return body.get("next_cursor")

    def meta(self, body):
        return {k: v for k, v in body.items() if k != "results"}

    No inheritance is required; any object with these five methods satisfies the protocol.

    JSON:API unwrapping

    JsonApiUnwrapper in bibliofabric.unwrap is a ready-made ResponseUnwrapper for JSON:API envelopes, as served by DataCite:

    from bibliofabric import JsonApiUnwrapper

unwrapper = JsonApiUnwrapper(cursor_param="page[cursor]")
    • results() returns the data list members that are objects: raw JSON:API resource objects with id, type, attributes, and relationships.
    • item() returns the single data object, or {} when there is none.
    • total() returns meta.total when it is an integer.
    • next_cursor() reads the cursor_param query parameter from the links.next URL.
    • meta() returns the envelope minus data.

    class JsonApiUnwrapper:
    """Read a JSON:API envelope (``data``, ``meta``, ``links``).

    Args:
        cursor_param: Name of the cursor query parameter that ``links.next``
            carries on later pages (``"page[cursor]"`` for DataCite).

    Records are the raw JSON:API resource objects (``id``, ``type``,
    ``attributes``, ``relationships``); a client that models flat records
    subclasses this and reshapes them. The total is ``meta.total``, and
    :meth:`meta` returns the rest of the envelope (``meta``, ``links``,
    ``included``).
    """

    def __init__(self, cursor_param: str = "page[cursor]") -> None:
        self._cursor_param = cursor_param

    def _data(self, body: Any) -> Any:
        return body.get("data") if isinstance(body, dict) else None

    def results(self, body: Any) -> list[dict[str, Any]]:
        """Return the ``data`` members that are objects, in order."""
        data = self._data(body)
        if not isinstance(data, list):
            return []
        return [item for item in data if isinstance(item, dict)]

    def item(self, body: Any) -> dict[str, Any]:
        """Return the single ``data`` object, or ``{}`` when it is not one."""
        data = self._data(body)
        return data if isinstance(data, dict) else {}

    def total(self, body: Any) -> int | None:
        """Return ``meta.total`` when it is an integer."""
        meta = body.get("meta") if isinstance(body, dict) else None
        total = meta.get("total") if isinstance(meta, dict) else None
        if isinstance(total, int) and not isinstance(total, bool):
            return total
        return None

    def next_cursor(self, body: Any) -> str | None:
        """Return the cursor query parameter value of ``links.next``, if any."""
        links = body.get("links") if isinstance(body, dict) else None
        next_url = links.get("next") if isinstance(links, dict) else None
        if not isinstance(next_url, str):
            return None
        values = parse_qs(urlsplit(next_url).query).get(self._cursor_param, [])
        return values[0] if values and values[0] else None

    def meta(self, body: Any) -> dict[str, Any]:
        """Return the envelope minus ``data``."""
        if not isinstance(body, dict):
            return {}
        return {key: value for key, value in body.items() if key != "data"}
