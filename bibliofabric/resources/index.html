    Resources

    ResourceClient[E] is a generic client for one API endpoint. Declare the endpoint path, the entity model, and the query dialect; override hook methods where the API deviates from the defaults. Both path= and dialect= may also be overridden per instance in the constructor.

    class Works(ResourceClient[Work]):
    path = "works"
    model = Work
    dialect = DIALECT

    Operations

    • get(id, *, select=None, params=None) fetches one entity (str or int id); a 404 raises NotFoundError.
    • exists(id) sends a HEAD request and returns True or False (on 404).
    • search(filters, ..., on_error="raise", failures=None) fetches one page and returns a Page[E] with results, total, next_cursor, page, and meta. Filters accept a pydantic model or a plain dict. Passing unsupported dialect parameters (query, select, sort, cursor, or page) or exceeding dialect.max_offset raises ConfigurationError before any request is sent.
    • iterate(...) yields entities across pages. It uses cursor paging when the dialect has a cursor_param, otherwise page or offset paging (or fetches once for unpaged dialects where page_param and offset_param are None). It stops at limit, on an empty page, or when there is no next cursor. on_page(page_number, next_cursor) checkpoints progress; passing a saved cursor back via cursor= resumes a cursor-mode harvest.
    • first(...) returns the first matching entity (defaulting page_size=1), or None.
    • count() reads the unwrapper total from a minimal page.
    • batch_get(ids, field="id", select=None, batch_size=None, concurrency=4, on_error="raise", failures=None) normalizes and deduplicates ids, fetches them in concurrent chunks (capped at dialect.max_page_size), and returns a dict keyed by normalized id. Missing ids are absent from the result.

    On the default on_error="raise" path, search(), batch_get(), and iterate() bulk-validate each page or chunk with a lazily cached TypeAdapter(list[E]) per subclass, falling back to per-record validation only when a record fails so ValidationError.raw still attaches the offending record.

    Hooks

    Override these methods on subclasses:

    • build_filter_params(filters) — filter serialization (OpenAlex joins filters into one filter parameter).
    • format_sort(sort) — sort parameter shape (Crossref splits sort/order).
    • build_batch_params(field, values) — batch OR syntax (OpenAlex and OpenAIRE use pipe-separated values in one filter parameter; Crossref repeats keys like doi:a,doi:b).
    • _fetch_batch_chunk(field, chunk, *, select=None) — chunk transport for batch_get; override for POST-batch APIs (such as Semantic Scholar) or path-encoded batch endpoints while keeping chunking, deduplication, concurrency, validation, on_error/failures, and keying.
    • normalize_id(value) — canonical identifier form (DOIs via bibliofabric.ids.normalize_doi).
    • record_keys(entity, field) — normalized keys an entity matches in batch_get.
    • item_path(id) — single-entity path; the default URL-encodes the id.
    • default_params() — query parameters sent with every list request (search(), iterate(), count(), and each batch_get chunk). Returns {} by default. Filter parameters and caller-supplied params= take precedence, so the hook is for API-wide requirements such as Europe PMC's format=json.
    • search_path(query) — route for search, iterate(), count(), and batch requests. The default returns self.path. Override it for APIs that carry the query in the path (DOAJ's /search/journals/{query}). With such an override, query= is accepted even when dialect.query_param is None; otherwise that combination raises ConfigurationError. query is None for count() without a query and for batch chunks.

    params= is the escape hatch for API extras (facets, sample, seed); typed wrappers for those belong on resource subclasses.

    class ResourceClient[E: BaseModel]:
    """Typed client for one API resource.

    Class attributes:

    - ``path``: endpoint path relative to the client's base URL, e.g. ``"works"``.
      Pass ``path=`` to the constructor for routes bound to a parent id,
      e.g. ``"members/297/works"``.
    - ``model``: the pydantic model a single entity validates against.
    - ``dialect``: the :class:`QueryDialect` of the API (usually shared); may
      also be overridden per instance via ``dialect=``.
    - ``filters_model``: optional declaration of the accepted filter model.
    - ``batch_size``: ids per ``batch_get`` chunk; ``0`` disables ``batch_get``.
    """

    path: str
    model: type[E]
    dialect: ClassVar[QueryDialect]
    filters_model: ClassVar[type[BaseModel] | None] = None
    batch_size: ClassVar[int] = 50
    _list_adapter: ClassVar[TypeAdapter[Any] | None] = None
    _list_adapter_model: ClassVar[type[BaseModel] | None] = None

    def __init__(
        self,
        client: BaseApiClient,
        *,
        path: str | None = None,
        dialect: QueryDialect | None = None,
    ) -> None:
        self._client = client
        if path is not None:
            self.path = path
        if dialect is not None:
            self.__dict__["dialect"] = dialect

    # --- hooks ---------------------------------------------------------

    def build_filter_params(
        self, filters: BaseModel | Mapping[str, Any] | None
    ) -> dict[str, str]:
        """Convert filter criteria into query parameters.

        The default dumps pydantic models (excluding ``None`` fields, using
        aliases), skips ``None`` entries in plain mappings, formats booleans as
        lowercase ``"true"``/``"false"``, and stringifies other values. Override
        for APIs that encode filters as a single structured parameter.
        """
        if filters is None:
            return {}
        if isinstance(filters, BaseModel):
            dumped = filters.model_dump(exclude_none=True, by_alias=True)
        else:
            dumped = {key: value for key, value in filters.items() if value is not None}
        params: dict[str, str] = {}
        for key, value in dumped.items():
            if isinstance(value, bool):
                params[str(key)] = "true" if value else "false"
            elif isinstance(value, str):
                params[str(key)] = value
            else:
                params[str(key)] = str(value)
        return params

    def format_sort(self, sort: str | Sequence[str]) -> dict[str, str]:
        """Convert a sort request into query parameters.

        The default sends ``<sort_param>: <value>``, joining sequences with a
        comma. Override for APIs that split field and direction into separate
        parameters (e.g. ``{"sort": "score", "order": "desc"}``).
        """
        if self.dialect.sort_param is None:
            return {}
        value = sort if isinstance(sort, str) else ",".join(sort)
        return {self.dialect.sort_param: value}

    def build_batch_params(self, field: str, values: Sequence[str]) -> dict[str, Any]:
        """Build the query parameters for one ``batch_get`` chunk.

        The default repeats the key once per value. Override for APIs that
        require an OR-list syntax in a single parameter.
        """
        return {field: list(values)}

    def default_params(self) -> Mapping[str, Any]:
        """Query parameters sent with every list, ``count()``, and batch request.

        Override for APIs that need a constant parameter on list routes (for
        example Europe PMC's ``format=json``, whose default is XML). Filter
        parameters and caller-supplied ``params`` take precedence.
        """
        return {}

    def search_path(self, query: str | None) -> str:
        """Return the list route for a search, ``count()``, or batch request.

        The default is :attr:`path`. Override for APIs that carry the query in
        the path instead of a query parameter (for example DOAJ's
        ``/search/journals/{query}``). Such an override makes ``query=``
        valid on a dialect whose ``query_param`` is ``None``. ``query`` is
        ``None`` for ``count()`` without one and for batch chunks.
        """
        return self.path

    async def _fetch_batch_chunk(
        self,
        field: str,
        chunk: list[str],
        *,
        select: Sequence[str] | None = None,
    ) -> tuple[list[dict[str, Any]], httpx.Response]:
        """Fetch raw records for one ``batch_get`` chunk.

        The default issues a ``GET`` using :meth:`build_batch_params` and
        unwraps records via ``unwrapper.results``. Override for APIs that use
        ``POST`` batch bodies (for example Semantic Scholar) or path-encoded
        batch endpoints while inheriting chunking, deduplication, concurrency,
        validation, ``on_error`` handling, and keying from :meth:`batch_get`.
        """
        query_params: dict[str, Any] = {
            **self.default_params(),
            **self.build_batch_params(field, chunk),
        }
        if self.dialect.page_size_param is not None:
            query_params[self.dialect.page_size_param] = len(chunk)
        if select is not None:
            if self.dialect.select_param is None:
                raise ConfigurationError(
                    f"{type(self).__name__} does not support field selection "
                    "(dialect.select_param is None)."
                )
            if select:
                query_params[self.dialect.select_param] = ",".join(select)
        response = await self._client.request(
            "GET", self.search_path(None), params=query_params
        )
        records = self._client.unwrapper.results(self._client.parse_json(response))
        return records, response

    def normalize_id(self, value: str) -> str:
        """Canonicalize an identifier before use in paths, batches, and keys."""
        return value.strip()

    def record_keys(self, entity: E, field: str) -> list[str]:
        """Return every normalized ``field`` value of ``entity``.

        ``batch_get`` keys each entity by whichever of these values was
        requested, so records carrying several ids (for example deduplicated
        records with many DOIs) land under the id the caller asked for.
        Override when the values live somewhere other than ``entity.<field>``.
        """
        value = getattr(entity, field, None)
        if value is None:
            value = getattr(entity, "id", None)
        values = value if isinstance(value, list) else [value]
        return [self.normalize_id(str(item)) for item in values if item is not None]

    def item_path(self, id: str | int) -> str:
        """Return the single-entity path for ``id``, URL-encoding it."""
        normalized = self.normalize_id(str(id))
        if not normalized:
            raise ConfigurationError(
                f"{type(self).__name__}.item_path requires a non-empty id."
            )
        return f"{self.path.rstrip('/')}/{quote(normalized, safe='')}"

    # --- operations ----------------------------------------------------

    async def get(
        self,
        id: str | int,
        *,
        select: Sequence[str] | None = None,
        params: Mapping[str, Any] | None = None,
    ) -> E:
        """Fetch one entity by id; 404 raises :class:`NotFoundError`."""
        query_params: dict[str, Any] = {}
        if select is not None:
            if self.dialect.select_param is None:
                raise ConfigurationError(
                    f"{type(self).__name__} does not support field selection "
                    "(dialect.select_param is None)."
                )
            if select:
                query_params[self.dialect.select_param] = ",".join(select)
        if params is not None:
            query_params.update(params)
        response = await self._client.request(
            "GET",
            self.item_path(id),
            params=query_params or None,
        )
        body = self._client.parse_json(response)
        data = self._client.unwrapper.item(body)
        return self._validate(
            data, request=_response_request(response), response=response
        )

    async def exists(self, id: str | int) -> bool:
        """Return ``True`` when ``id`` exists (HTTP HEAD); 404 returns ``False``."""
        try:
            await self._client.request("HEAD", self.item_path(id))
        except NotFoundError:
            return False
        return True

    async def search(
        self,
        filters: BaseModel | Mapping[str, Any] | None = None,
        *,
        query: str | None = None,
        sort: str | Sequence[str] | None = None,
        select: Sequence[str] | None = None,
        page: int | None = None,
        page_size: int | None = None,
        cursor: str | None = None,
        on_error: OnError = "raise",
        failures: list[tuple[dict[str, Any], Exception]] | None = None,
        params: Mapping[str, Any] | None = None,
    ) -> Page[E]:
        """Fetch one page of results as a typed :class:`Page`.

        ``params`` is the escape hatch for API extras (facets, ``sample``,
        ``seed``); typed wrappers for them belong on client subclasses.
        Records that fail validation raise :class:`ValidationError` by default,
        or are skipped and recorded in ``failures`` with ``on_error="skip"``.
        """
        _check_on_error(on_error)
        query_params = self._search_params(
            filters=filters,
            query=query,
            sort=sort,
            select=select,
            page=page,
            page_size=page_size,
            cursor=cursor,
            params=params,
        )
        response = await self._client.request(
            "GET", self.search_path(query), params=query_params
        )
        body = self._client.parse_json(response)
        unwrapper = self._client.unwrapper
        results = self._validate_records(
            unwrapper.results(body),
            on_error=on_error,
            failures=failures,
            request=_response_request(response),
            response=response,
        )
        effective_page = page
        if (
            effective_page is None
            and cursor is None
            and (
                self.dialect.offset_param is not None
                or self.dialect.page_param is not None
            )
        ):
            effective_page = self.dialect.page_start
        return Page(
            results=results,
            total=unwrapper.total(body),
            next_cursor=unwrapper.next_cursor(body),
            page=effective_page,
            meta=unwrapper.meta(body),
        )

    def iterate(
        self,
        filters: BaseModel | Mapping[str, Any] | None = None,
        *,
        query: str | None = None,
        sort: str | Sequence[str] | None = None,
        select: Sequence[str] | None = None,
        page_size: int | None = None,
        limit: int | None = None,
        cursor: str | None = None,
        on_error: OnError = "raise",
        failures: list[tuple[dict[str, Any], Exception]] | None = None,
        on_page: Callable[[int, str | None], Any] | None = None,
        params: Mapping[str, Any] | None = None,
    ) -> AsyncIterator[E]:
        """Iterate over all matching entities.

        Uses cursor paging when ``dialect.cursor_param`` is set, otherwise page
        or offset paging. Stops at ``limit``, on an empty page, or when the
        unwrapper reports no next cursor. ``on_page(page_number, next_cursor)``
        checkpoints progress; passing a saved cursor back via ``cursor=``
        resumes a cursor-mode harvest. Records that fail validation raise
        :class:`ValidationError`, or are dropped and recorded in ``failures``
        with ``on_error="skip"``.
        """
        _check_on_error(on_error)
        if limit is not None and limit < 0:
            raise ConfigurationError(f"limit must be non-negative, got {limit}.")

            raise ConfigurationError(
                f"{type(self).__name__} does not support cursor paging "
                "(dialect.cursor_param is None)."
            )
        if self.dialect.cursor_param is not None:
            return self._iterate_cursor(
                filters=filters,
                query=query,
                sort=sort,
                select=select,
                page_size=page_size,
                limit=limit,
                cursor=cursor,
                on_error=on_error,
                failures=failures,
                on_page=on_page,
                params=params,
            )
        return self._iterate_pages(
            filters=filters,
            query=query,
            sort=sort,
            select=select,
            page_size=page_size,
            limit=limit,
            on_error=on_error,
            failures=failures,
            on_page=on_page,
            params=params,
        )

    async def batch_get(
        self,
        ids: Sequence[str],
        *,
        field: str = "id",
        select: Sequence[str] | None = None,
        batch_size: int | None = None,
        concurrency: int = 4,
        on_error: OnError = "raise",
        failures: list[tuple[dict[str, Any], Exception]] | None = None,
    ) -> dict[str, E]:
        """Fetch entities for many ids in bounded, concurrent chunks.

        Ids are normalized with :meth:`normalize_id` and deduplicated, split
        into chunks of ``batch_size`` (capped at ``dialect.max_page_size``),
        fetched concurrently under ``concurrency``, and returned keyed by
        normalized id. Missing ids are absent from the result. Each entity is
        keyed by the requested ids found among :meth:`record_keys`. Records
        that fail validation raise :class:`ValidationError` by default, or are
        skipped and recorded in ``failures`` with ``on_error="skip"``.
        """
        _check_on_error(on_error)
        if batch_size is None:
            size = self.batch_size
            if size <= 0:
                raise ConfigurationError(
                    f"{type(self).__name__}.batch_get is disabled (batch_size={size})."
                )
        else:
            if batch_size <= 0:
                raise ConfigurationError(
                    f"batch_size must be positive, got {batch_size}."
                )
            size = batch_size
        if concurrency <= 0:
            raise ConfigurationError(
                f"concurrency must be positive, got {concurrency}."
            )
        effective_size = min(size, self.dialect.max_page_size)
        keys = list(dict.fromkeys(self.normalize_id(value) for value in ids))
        if not keys:
            return {}
        chunks = [
            keys[start : start + effective_size]
            for start in range(0, len(keys), effective_size)
        ]

        async def fetch_chunk(
            chunk: list[str],
        ) -> tuple[dict[str, E], list[tuple[dict[str, Any], Exception]]]:
            records, response = await self._fetch_batch_chunk(
                field, chunk, select=select
            )
            requested = set(chunk)
            chunk_results: dict[str, E] = {}
            chunk_failures: list[tuple[dict[str, Any], Exception]] = []
            entities = self._validate_records(
                records,
                on_error=on_error,
                failures=chunk_failures if failures is not None else None,
                request=_response_request(response),
                response=response,
            )
            for entity in entities:
                for key in self.record_keys(entity, field):
                    if key in requested:
                        chunk_results[key] = entity
            return chunk_results, chunk_failures

        chunk_outputs = await run_bounded(fetch_chunk, chunks, concurrency)
        results: dict[str, E] = {}
        for chunk_results, chunk_failures in chunk_outputs:
            results.update(chunk_results)
            if failures is not None:
                failures.extend(chunk_failures)
        return results

    def _search_params(
        self,
        *,
        filters: BaseModel | Mapping[str, Any] | None,
        query: str | None = None,
        sort: str | Sequence[str] | None = None,
        select: Sequence[str] | None = None,
        page: int | None = None,
        page_size: int | None = None,
        cursor: str | None = None,
        params: Mapping[str, Any] | None,
    ) -> dict[str, Any]:
        dialect = self.dialect
        if isinstance(filters, str):
            raise ConfigurationError(
                f"Got a string as filters ({filters!r}). Pass search text as "
                f"query={filters!r}; filters takes a filter model or a mapping."
            )
        if cursor is not None and dialect.cursor_param is None:
            raise ConfigurationError(
                f"{type(self).__name__} does not support cursor paging "
                "(dialect.cursor_param is None)."
            )
        if (
            page is not None
            and dialect.page_param is None
            and dialect.offset_param is None
        ):
            raise ConfigurationError(
                f"{type(self).__name__} does not support page/offset paging "
                "(dialect.page_param and dialect.offset_param are both None)."
            )
        if (
            query is not None
            and dialect.query_param is None
            and self.search_path(query) == self.search_path(None)
        ):
            raise ConfigurationError(
                f"{type(self).__name__} does not support free-text query "
                "(dialect.query_param is None and search_path ignores it)."
            )
        if select is not None and dialect.select_param is None:
            raise ConfigurationError(
                f"{type(self).__name__} does not support field selection "
                "(dialect.select_param is None)."
            )
        if sort is not None and dialect.sort_param is None:
            raise ConfigurationError(
                f"{type(self).__name__} does not support sorting "
                "(dialect.sort_param is None)."
            )
        query_params: dict[str, Any] = {
            **self.default_params(),
            **self.build_filter_params(filters),
        }
        size = (
            dialect.default_page_size
            if page_size is None
            else min(page_size, dialect.max_page_size)
        )
        if dialect.page_size_param is not None:
            query_params[dialect.page_size_param] = size
        if cursor is not None and dialect.cursor_param is not None:
            query_params[dialect.cursor_param] = cursor
        elif dialect.offset_param is not None:
            effective_page = dialect.page_start if page is None else page
            offset = (effective_page - dialect.page_start) * size
            if dialect.max_offset is not None and offset > dialect.max_offset:
                raise ConfigurationError(
                    f"Requested offset {offset} exceeds QueryDialect.max_offset "
                    f"({dialect.max_offset})."
                )
            query_params[dialect.offset_param] = offset
        elif dialect.page_param is not None:
            effective_page = dialect.page_start if page is None else page
            offset = (effective_page - dialect.page_start) * size
            if dialect.max_offset is not None and offset > dialect.max_offset:
                raise ConfigurationError(
                    f"Requested offset {offset} exceeds QueryDialect.max_offset "
                    f"({dialect.max_offset})."
                )
            query_params[dialect.page_param] = effective_page
        if query is not None and dialect.query_param is not None:
            query_params[dialect.query_param] = query
        if select and dialect.select_param is not None:
            query_params[dialect.select_param] = ",".join(select)
        if sort is not None:
            query_params.update(self.format_sort(sort))
        if params is not None:
            query_params.update(params)
        return query_params

    def _get_list_adapter(self) -> TypeAdapter[list[E]]:
        cls = type(self)
        adapter = cls.__dict__.get("_list_adapter")
        if adapter is None or cls.__dict__.get("_list_adapter_model") is not self.model:
            list_type: Any = GenericAlias(list, (self.model,))
            adapter = TypeAdapter(list_type)
            cls._list_adapter = adapter
            cls._list_adapter_model = self.model
        return cast(TypeAdapter[list[E]], adapter)

    def _validate(
        self,
        data: dict[str, Any],
        *,
        request: httpx.Request | None = None,
        response: httpx.Response | None = None,
    ) -> E:
        return validate_model(self.model, data, request=request, response=response)

    def _validate_records(
        self,
        records: list[dict[str, Any]],
        *,
        on_error: OnError,
        failures: list[tuple[dict[str, Any], Exception]] | None,
        request: httpx.Request | None = None,
        response: httpx.Response | None = None,
    ) -> list[E]:
        """Validate a page or chunk of records.

        Uses the lazily cached ``TypeAdapter(list[E])`` on the ``on_error="raise"``
        fast path, falling back to per-record :meth:`_validate` only when
        validation fails so ``ValidationError.raw`` still carries the offending
        record.
        """
        if not records:
            return []
        if on_error == "raise":
            try:
                return self._get_list_adapter().validate_python(records)
            except PydanticValidationError:
                for record in records:
                    self._validate(record, request=request, response=response)
                raise  # pragma: no cover
        validated: list[E] = []
        for record in records:
            entity = self._parse_or_handle(
                record,
                on_error=on_error,
                failures=failures,
                request=request,
                response=response,
            )
            if entity is not None:
                validated.append(entity)
        return validated

    def _parse_or_handle(
        self,
        record: dict[str, Any],
        *,
        on_error: OnError,
        failures: list[tuple[dict[str, Any], Exception]] | None,
        request: httpx.Request | None = None,
        response: httpx.Response | None = None,
    ) -> E | None:
        """Validate a record; on failure raise, or skip and record it."""
        try:
            return self.model.model_validate(record)
        except PydanticValidationError as error:
            if on_error == "skip":
                if failures is not None:
                    failures.append((record, error))
                logger.warning(
                    "Skipping record that failed %s validation: %s",
                    self.model.__name__,
                    error,
                )
                return None
            return validate_model(
                self.model, record, request=request, response=response
            )

    async def _iterate_cursor(
        self,
        *,
        filters: BaseModel | Mapping[str, Any] | None,
        query: str | None,
        sort: str | Sequence[str] | None,
        select: Sequence[str] | None,
        page_size: int | None,
        limit: int | None,
        cursor: str | None,
        on_error: OnError,
        failures: list[tuple[dict[str, Any], Exception]] | None,
        on_page: Callable[[int, str | None], Any] | None,
        params: Mapping[str, Any] | None,
    ) -> AsyncIterator[E]:
        if limit == 0:
            return
        dialect = self.dialect
        if page_size is None:
            page_size = dialect.iterate_page_size
        current = cursor if cursor is not None else dialect.cursor_start
        page_number = 0
        fetched = 0
        while True:
            query_params = self._search_params(
                filters=filters,
                query=query,
                sort=sort,
                select=select,
                page=None,
                page_size=page_size,
                cursor=current,
                params=params,
            )
            response = await self._client.request(
                "GET", self.search_path(query), params=query_params
            )
            body = self._client.parse_json(response)
            unwrapper = self._client.unwrapper
            results = unwrapper.results(body)
            next_cursor = unwrapper.next_cursor(body)
            if next_cursor == current:  # Solr-style APIs echo the cursor when exhausted
                next_cursor = None
            page_number += 1
            stopped = False
            req = _response_request(response)
            if on_error == "raise":
                batch = results[: limit - fetched] if limit is not None else results
                entities = self._validate_records(
                    batch,
                    on_error="raise",
                    failures=None,
                    request=req,
                    response=response,
                )
                for entity in entities:
                    yield entity
                    fetched += 1
                    if limit is not None and fetched >= limit:
                        stopped = True
                        break
            else:
                for record in results:
                    entity = self._parse_or_handle(
                        record,
                        on_error=on_error,
                        failures=failures,
                        request=req,
                        response=response,
                    )
                    if entity is None:
                        continue
                    yield entity
                    fetched += 1
                    if limit is not None and fetched >= limit:
                        stopped = True
                        break
            await _fire_on_page(on_page, page_number, next_cursor)
            if stopped or not results or next_cursor is None:
                return
            current = next_cursor

    async def _iterate_pages(
        self,
        *,
        filters: BaseModel | Mapping[str, Any] | None,
        query: str | None,
        sort: str | Sequence[str] | None,
        select: Sequence[str] | None,
        page_size: int | None,
        limit: int | None,
        on_error: OnError,
        failures: list[tuple[dict[str, Any], Exception]] | None,
        on_page: Callable[[int, str | None], Any] | None,
        params: Mapping[str, Any] | None,
    ) -> AsyncIterator[E]:
        if limit == 0:
            return
        if page_size is None:
            page_size = self.dialect.iterate_page_size
        has_paging = (
            self.dialect.page_param is not None or self.dialect.offset_param is not None
        )
        page = self.dialect.page_start
        fetched = 0
        seen = 0
        while True:
            query_params = self._search_params(
                filters=filters,
                query=query,
                sort=sort,
                select=select,
                page=page if has_paging else None,
                page_size=page_size,
                params=params,
            )
            response = await self._client.request(
                "GET", self.search_path(query), params=query_params
            )
            body = self._client.parse_json(response)
            unwrapper = self._client.unwrapper
            results = unwrapper.results(body)
            total = unwrapper.total(body)
            seen += len(results)
            stopped = False
            req = _response_request(response)
            if on_error == "raise":
                batch = results[: limit - fetched] if limit is not None else results
                entities = self._validate_records(
                    batch,
                    on_error="raise",
                    failures=None,
                    request=req,
                    response=response,
                )
                for entity in entities:
                    yield entity
                    fetched += 1
                    if limit is not None and fetched >= limit:
                        stopped = True
                        break
            else:
                for record in results:
                    entity = self._parse_or_handle(
                        record,
                        on_error=on_error,
                        failures=failures,
                        request=req,
                        response=response,
                    )
                    if entity is None:
                        continue
                    yield entity
                    fetched += 1
                    if limit is not None and fetched >= limit:
                        stopped = True
                        break
            await _fire_on_page(on_page, page, None)
            if (
                stopped
                or not has_paging
                or not results
                or (total is not None and seen >= total)
            ):
                return
            page += 1

    def build_filter_params(
    self, filters: BaseModel | Mapping[str, Any] | None
) -> dict[str, str]:
    """Convert filter criteria into query parameters.

    The default dumps pydantic models (excluding ``None`` fields, using
    aliases), skips ``None`` entries in plain mappings, formats booleans as
    lowercase ``"true"``/``"false"``, and stringifies other values. Override
    for APIs that encode filters as a single structured parameter.
    """
    if filters is None:
        return {}
    if isinstance(filters, BaseModel):
        dumped = filters.model_dump(exclude_none=True, by_alias=True)
    else:
        dumped = {key: value for key, value in filters.items() if value is not None}
    params: dict[str, str] = {}
    for key, value in dumped.items():
        if isinstance(value, bool):
            params[str(key)] = "true" if value else "false"
        elif isinstance(value, str):
            params[str(key)] = value
        else:
            params[str(key)] = str(value)

        meta=unwrapper.meta(body),
    )
