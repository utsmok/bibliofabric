# Academic APIs Catalog: Authority Registries, Organizations, Venues, Funders & Taxonomies

This catalog covers the canonical authority registries, persistent-identifier
routers, and controlled vocabularies needed to anchor authors, institutions,
journals, books, publishers, funders, grants, and subjects across scholarly
graphs.

**Priority Tiers:**

- **P0 (Foundational Backbone):** Required for canonical entity grounding; build
  first (Wave 1).
- **P1 (High Canonical Value):** High-impact enrichment sources (Wave 2).
- **P2 (Domain / Regional Enrichment):** Valuable regional or discipline
  authorities and lightweight helpers.
- **P3 (Bulk Table / Commercial / Skip):** Periodic CSV lookup tables,
  paywalled services, or closed portals.
