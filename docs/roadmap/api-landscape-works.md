# Academic APIs Catalog: Works, Citations, Preprints, Data, Software, OA & Integrity

This catalog evaluates scholarly literature, citation graph, preprint, research
data, software, open-access, and research-integrity APIs against 2025–2026
platform status and `bibliofabric` 0.7 capabilities.

**Priority Tiers:**

- **Tier 1 (Wave 1 / Next Up):** Highest canonical value, open/permissive
  licensing, clean REST/JSON (or essential preprint coverage).
- **Tier 2 (Wave 2 / High-Value Specialist):** Strong domain/data/software
  authority or reusable protocol adapters.
- **Tier 3 (Restricted / Niche / Deprecated):** Paywalled, non-redistributable
  ToS, narrow niche, or sunset endpoints.

## Decentralized Standards & Shared Protocol Adapters

Rather than building single-site wrappers for hundreds of institutional
repositories, `bibliofabric` and the canonical layer can support four open
standards as reusable protocol adapters:

| Standard | Specification | Wire Format | Role in Stack | Target Layer | Priority |
|---|---|---|---|---|---|
| **OAI-PMH** | [openarchives.org/pmh](https://www.openarchives.org/pmh/) | XML (`resumptionToken` cursors) | Universal fallback metadata harvester for institutional repos, EarthArXiv, PhilArchive, arXiv bulk. | Shared `bibliofabric` XML harvester mixin | **Tier 2** |
| **FAIR Signposting** | [signposting.org](https://signposting.org) | HTTP `HEAD` / `Link` headers (`cite-as`, `author`, `describedby`, `license`) | Discover canonical PIDs, authors, licenses, and machine-readable metadata URLs on any scholarly landing page. | Shared `bibliofabric` `Link`-header helper | **Tier 2** |
| **CodeMeta & `CITATION.cff`** | [codemeta.github.io](https://codemeta.github.io)<br>[citation-file-format.github.io](https://citation-file-format.github.io) | JSON-LD (`codemeta.json`) & YAML (`CITATION.cff`) | Parse intrinsic software citation metadata directly from GitHub/GitLab, Zenodo, or Software Heritage archives. | Canonical fusion `Software` entity parsers | **Tier 2** |
| **COAR Notify** | [coar-notify.net](https://coar-notify.net) | Linked Data Notifications / ActivityStreams 2.0 | Link preprints, peer reviews, overlay journals, and Software Heritage deposits via standardized event payloads. | Canonical fusion event/relation adapter | **Tier 2** |
