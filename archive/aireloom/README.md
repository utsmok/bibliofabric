# Archive

Historical documents kept for reference. Nothing in this folder is maintained
or referenced by the library.

- `AIRELOOM_IMPROVEMENT_PLAN.md` — improvement plan from 2026-06-05. Its items
  are done or superseded by the 2026-11 overhaul.
- `ERGONOMICS_PLAN.md` — design record of the ergonomics layer. Its rules for
  which fields get which type are the spec the safe-types review finding is
  judged against.
- `OPENAIRE_BUG_REPORT.md` — investigation of 21 upstream OpenAIRE API issues,
  2026-06-04.
- `OPENAIRE_V3_INVESTIGATION_REPORT.md` — investigation of the OpenAIRE Graph
  API V3 surface: links endpoint quirks, page caps, and the V4 beta
  announcement.
- `verification_script.py` — live-API verification harness used before
  releases. Superseded by the marker-gated live tests in
  `tests/_legacy/test_actual_data.py` and the examples.

The rendered HTML copies of the two OpenAIRE reports were deleted; regenerate
them from the markdown with StackEdit if needed.
